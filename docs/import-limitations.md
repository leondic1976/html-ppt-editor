# 가져오기 한계

임의의 HTML은 구조가 제각각이므로 무엇이든 완벽히 편집할 수 있다고 약속하지 않습니다. 앱은 파일을 열 때 아래 내용을 가져오기 보고서로 알려 줍니다.

## 편집 수준

| 수준         | 고칠 수 있는 것                                                | 대가                                                                       |
| ------------ | -------------------------------------------------------------- | -------------------------------------------------------------------------- |
| L1 원본 편집 | 정적 글자, `<img>`·SVG `<image>`·인라인 배경 사진, 인라인 서식 | 위치를 옮길 수 없음. 나머지는 바이트까지 보존                              |
| L2 요소 편집 | L1 + 이동·크기 조절                                            | flex/grid가 고정 좌표로 바뀌고, 저장 형식이 네이티브로 바뀜. 스크립트 제거 |
| L3 화면 고정 | 위에 새 요소 추가                                              | 원래 내용은 그림이 되어 수정 불가                                          |

## 슬라이드 인식

`[data-slide]`, reveal.js 구조, `section.slide`, `.slide`, `.swiper-slide`, `.remark-slide`, `.ppt-slide`, `.page`, `body > section`, 반복되는 형제 요소 순으로 찾습니다. 찾지 못하면 페이지를 임의로 나누지 않고, 전체를 한 장으로 열거나 CSS 선택자로 지정하게 합니다.

## 알려진 제약

- **스크립트가 만드는 내용은 보이지 않습니다.** 파일의 스크립트를 실행하지 않기 때문입니다. 스크립트로 그리는 차트(Chart.js 등)는 빈 칸으로, 내용을 스크립트 안에 둔 파일은 빈 슬라이드로 보입니다. 앱이 이런 파일을 감지하면 알려 줍니다. 브라우저 개발자 도구에서 렌더링된 HTML을 저장해 열면 편집할 수 있습니다.
- **Tailwind CDN 같은 스크립트 기반 CSS**를 쓰는 파일은 스타일이 빠져 보입니다. 파일 자체는 바뀌지 않습니다.
- **외부 리소스**는 기본으로 차단됩니다. 보기 메뉴에서 허용할 수 있습니다(스크립트는 계속 차단).
- **파일 밖 이미지:** HTML과 이미지를 함께 끌어다 놓으면 파일 이름으로 연결됩니다.
- **애니메이션**은 끝 상태로 표시됩니다. 스크립트로 나타나는 요소는 숨겨진 채일 수 있습니다.
- **doctype이 없는 문서:** `srcdoc` iframe은 항상 표준 모드로 렌더링되므로, 쿼크 모드에 의존하던 레이아웃이 달라질 수 있습니다.
- **`<picture>`의 `<source>`** 는 미리보기에서 제거되고 사진 교체 대상이 아닙니다.
- **CSS 스타일시트 안의 배경 이미지**는 L1 교체 대상이 아닙니다(인라인 `style`만).
- **`<canvas>`, `<video>`, `<audio>`** 는 L1 편집 대상이 아닙니다. L2에서 캡처를 시도하고, 실패하면 보고합니다.
- **EUC-KR 등 비UTF-8 파일**은 저장할 때 UTF-8로 변환하고 charset 선언을 고칩니다.
- **L2에서 근사되거나 손실되는 것:** 방향별 다른 테두리, 글자 그림자, 그라데이션 글자, 병합 셀 표(그림으로 고정), `backdrop-filter`·`filter`·`clip-path`·`mix-blend-mode`(그림으로 고정).
- **외부에서 수정된 저장본:** 편집 기록을 버리고 현재 내용을 새 원본으로 엽니다. 앱은 이를 경고합니다.

## 슬라이드 넘김 코드를 쓰는 파일을 저장하면

저장본에는 원본 스크립트가 그대로 남으므로, 브라우저에서 열면 원래처럼 동작합니다. 앱이 파일을 다시 쓰지 않고 고친 글자만 바꾸기 때문입니다.
