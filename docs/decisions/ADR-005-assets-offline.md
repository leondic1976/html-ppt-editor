# ADR-005: 자산 중복 제거와 오프라인 패키징

**결정.** 자산 ID는 내용의 SHA-256이고, 파일 안에 한 번만 저장합니다. 외부 URL 자산이 있으면 CSP에 `https:`를 추가하되 `selfContained: false`로 표시하고 사용자에게 알립니다.

- 20MB를 넘으면 HTML + assets ZIP을 권합니다. 20MB는 측정값이 아니라 초기 경고 기준입니다.
- ZIP을 읽을 때는 압축 해제 전에 목록의 크기·개수·압축률을 검사합니다.
- 다시 읽을 때 자산의 해시가 ID와 다르면 제외하고 변조 가능성을 경고합니다.

**글꼴.** 앱은 글꼴을 번들하지 않습니다. 기본 글꼴은 Windows에 있는 맑은 고딕입니다. Pretendard를 기본으로 하면 설치하지 않은 PC에서 HTML과 PPTX 모두 대체되기 때문입니다. 사용자가 글꼴 파일을 포함할 수 있고, 재배포 허용 여부를 묻습니다.

**서비스 워커 없음.** 사용자가 "발표 파일만 오프라인"을 선택했으므로 편집기 PWA는 만들지 않았습니다. 서비스 워커 캐시는 독립 파일의 오프라인성을 증명하지도 않습니다. 오프라인 검증은 네트워크를 끊고 `file://`로 엽니다.
