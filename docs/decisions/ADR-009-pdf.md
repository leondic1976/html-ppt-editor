# ADR-009: 브라우저 PDF와 Playwright PDF

**결정.** 앱 안에서는 브라우저 인쇄 창을 엽니다. 메뉴에 "인쇄 / PDF로 저장 (브라우저 인쇄 창)"으로 표시해, 앱이 PDF 파일을 만드는 것처럼 보이지 않게 합니다. 파일을 직접 만들어야 하면 로컬 명령 `pnpm deck-to-pdf`를 씁니다.

**서버 서비스를 만들지 않은 이유.** 파일을 서버로 보내지 않는 것이 이 앱의 약속입니다. 같은 Chromium 엔진을 사용자 PC에서 돌리면 프라이버시 비용 없이 같은 품질을 얻습니다. 대가는 설치(Chrome + Node)입니다.

**인쇄.** `@page`로 슬라이드 크기를 선언하고 여백 0, 슬라이드마다 페이지 나눔, `print-color-adjust: exact`를 적용합니다. 글꼴과 이미지를 기다린 뒤 인쇄합니다. 브라우저 설정의 "배경 그래픽"에 영향받을 수 있습니다.

**검증.** E2E에서 인쇄용 문서를 `page.pdf()`로 렌더링해 페이지 수(26장 → 26쪽)와 16:9 비율을 확인합니다. 실제 인쇄 창의 사람 조작은 자동화하지 않았습니다.
