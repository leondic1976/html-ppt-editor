# ADR-003: 캔버스 단위와 글꼴 변환

**결정.** 모델 좌표는 슬라이드 폭에 정규화한 논리 픽셀입니다. 슬라이드 폭을 13⅓인치로 고정하므로 1920폭에서 `x(in) = x / 144`, `fontSize(pt) = px × 0.5`입니다. 변환은 `document-core/src/units.ts` 한 곳에만 있습니다.

**이유.** CSS의 96 CSS px = 1인치를 쓰면 1920폭이 20인치가 되어 PowerPoint 기본 슬라이드와 맞지 않습니다. 줌은 CSS `transform`으로만 적용해 데이터가 줌에 영향받지 않습니다.

**검증.** 단위 테스트와 실제 PowerPoint에서 확인했습니다. 120 model-px → 60pt 위치, 100px 글자 → 50pt, 1920×1080 → 960×540pt입니다.
