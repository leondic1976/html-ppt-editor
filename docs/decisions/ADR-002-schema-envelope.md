# ADR-002: 문서 스키마 v2와 HTML 봉투

**결정.** 단일 HTML은 미리 렌더링한 슬라이드 DOM + JSON 모델 + 자산 저장소 + CSP로 고정한 런타임으로 구성합니다. 재편집은 JSON만 읽습니다.

**이유.**

- 런타임 렌더링만 쓰면 렌더러 전체를 파일에 넣어야 합니다. 미리 렌더링하면 파일에는 작은 런타임만 들어갑니다.
- DOM과 JSON에 이미지를 각각 base64로 넣으면 크기가 두 배가 되므로, `data-hps-asset`으로 저장소를 참조합니다. 발표 전용 파일은 모델이 없으므로 DOM에 직접 넣습니다.
- `file://`에서 서버 없이 열려야 합니다.

**JSON 삽입.** `JSON.stringify` 결과를 그대로 넣으면 `</script>`로 탈출할 수 있어, `<`, `>`, `&`, U+2028/9를 이스케이프합니다(`jsonForScriptTag`).

**측정.** 1×1 PNG를 두 슬라이드가 공유하는 덱에서 base64가 한 번만 나타나는 것을 테스트합니다. 큰 파일의 실제 크기·로딩 수치는 [G0 보고서](../phase0/G0-report.md)에 있습니다.
