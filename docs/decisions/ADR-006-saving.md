# ADR-006: 브라우저 저장 폴백과 백업

**결정.**

- Chrome/Edge는 File System Access API의 저장 창을 쓰고, 지원하지 않는 브라우저는 다운로드로 폴백합니다.
- **자동으로 원본을 덮어쓰지 않습니다.** 레거시 첫 저장은 `<이름>.edited.html`을 제안합니다. 사용자가 고른 파일에 다시 저장할 때는 변경 건수와 파일 이름을 확인합니다.
- 사용자가 저장 창을 취소하면 오류를 표시하지 않습니다. 권한 거부·디스크 부족은 원인과 함께 알리고 "저장 안 됨" 상태를 유지합니다.
- 저장 전에 모델을 다시 검증합니다.
- 자동 저장은 IndexedDB에 문서당 최근 20개까지 둡니다. 브라우저 데이터가 지워지면 사라지므로 영구 보존을 약속하지 않고, 실패하면 파일로 저장하라고 알립니다.

**레거시 세션.** 저장할 내용과 같은 바이트(사이드카 포함)를 파일 이름별로 하나 보관합니다. 복구는 그 바이트를 보통 파일처럼 다시 여는 것이므로 경로가 하나뿐입니다. 파일로 저장했거나 사용자가 닫으면 복구본을 지웁니다.
