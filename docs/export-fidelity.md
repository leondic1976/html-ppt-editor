# 내보내기 충실도

어떤 출력도 HTML과 픽셀까지 같다고 약속하지 않습니다. 브라우저, 글꼴, 인쇄 엔진, PowerPoint의 렌더러가 다르기 때문입니다.

## 출력 비교

| 출력               | 편집 가능성          | 보존 목표            | 비고                                           |
| ------------------ | -------------------- | -------------------- | ---------------------------------------------- |
| 편집 가능한 HTML   | 이 앱에서 재편집     | 네이티브 모델 전체   | 외부 리소스가 있으면 경고                      |
| 발표 전용 HTML     | 재편집 불가          | 화면                 | 모델을 빼서 작음                               |
| 레거시 저장본      | 이 앱에서 계속 수정  | 원본 바이트 + 수정분 | 원본 스크립트 유지                             |
| 인쇄 → PDF 저장    | 일반 PDF             | 선택 가능한 글자     | 브라우저 인쇄 창 사용. 앱이 파일을 만들지 않음 |
| `pnpm deck-to-pdf` | 일반 PDF             | 선택 가능한 글자     | Chrome + Node 필요                             |
| PPTX 편집 우선     | 글자·도형·선·표·차트 | 편집성               | 줄바꿈·효과 일부 다름                          |
| PPTX 외관 우선     | 슬라이드가 그림      | 외관                 | 글자 수정 불가                                 |

## 편집 우선 PPTX의 요소별 처리

| 요소                     | 처리                                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 글자                     | 네이티브 런: 굵기, 기울임, 밑줄, 취소선, 색, 크기, 링크, 자간, 줄 간격, 목록. 한 줄 상자는 줄바꿈을 꺼서 글자 폭 차이로 줄이 밀리지 않게 함 |
| 글자 굵기 500 등         | 일반 또는 굵게로 표현, 보고                                                                                                                 |
| 사진                     | PNG/JPEG/GIF는 그대로, WebP·AVIF·BMP는 PNG로 변환. cover/contain 유지                                                                       |
| 사진의 둥근 모서리       | 유지되지 않음, 보고                                                                                                                         |
| SVG                      | 네이티브 삽입                                                                                                                               |
| 단색 도형                | 네이티브: 채우기, 테두리, 파선, 모서리, 투명도, 그림자                                                                                      |
| 그라데이션 도형          | 이미지 폴백, 실패 시 첫 색상                                                                                                                |
| 직선                     | 네이티브: 화살표, 파선                                                                                                                      |
| 곡선                     | 이미지 폴백, 실패 시 직선                                                                                                                   |
| 표                       | 네이티브                                                                                                                                    |
| 차트                     | 네이티브 데이터 차트: 막대, 선, 영역, 원, 분산                                                                                              |
| 코드                     | 색이 입혀진 글자 상자                                                                                                                       |
| 그라데이션 슬라이드 배경 | 이미지 폴백, 실패 시 첫 색상. 슬라이드마다 PNG가 들어가 파일이 커짐(26장에 21.6MB)                                                          |
| 발표자 노트              | 유지                                                                                                                                        |
| 전환·애니메이션          | 없음                                                                                                                                        |
| 글꼴                     | 포함하지 않음. 받는 PC에 설치 필요, 보고서에 목록 표시                                                                                      |

레거시 덱은 L2 변환을 거치므로 [가져오기 한계](import-limitations.md)의 손실도 함께 보고됩니다.

## 확인한 것과 못 한 것

Microsoft PowerPoint 16(Windows)에서 파일을 열어 객체 종류, 좌표, 글자 크기, 노트를 읽고 렌더링을 직접 봤습니다. 복구 요청은 없었습니다.

**Keynote, Google Slides, LibreOffice 렌더링은 확인하지 않았습니다.** LibreOffice 변환은 CI의 스모크 테스트이며, 그 성공이 Office 호환을 뜻하지 않습니다. 결과가 깨지면 외관 우선으로 내보내세요.
