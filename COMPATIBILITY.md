# 호환성

표의 "확인"은 이 저장소의 자동 테스트나 직접 실행으로 확인했다는 뜻입니다. 확인 방법은 [G0 보고서](docs/phase0/G0-report.md)에 있습니다.

## 브라우저

| 브라우저         | 상태                                                                              |
| ---------------- | --------------------------------------------------------------------------------- |
| Chrome (Windows) | 확인: E2E 전체                                                                    |
| Edge (Windows)   | 확인: E2E 전체                                                                    |
| Firefox, Safari  | **확인하지 않음.** 저장은 다운로드로 대체되도록 만들었지만 실행해 보지 않았습니다 |
| macOS, Linux     | **확인하지 않음**                                                                 |

## 기존 HTML 유형별 편집 지원

모두 합성 샘플(`fixtures/legacy-html/`) 기준입니다. 실제 사용자 파일로는 아직 확인하지 않았습니다.

| 유형                                        | 슬라이드 인식   | L1 글자·사진   | 저장·재열기 | 비고                                                                      |
| ------------------------------------------- | --------------- | -------------- | ----------- | ------------------------------------------------------------------------- |
| `section.slide` + flex/grid, 정적           | 확인            | 확인           | 확인        | 원본 대비 픽셀 차이 0% (2장 기준)                                         |
| CSS로 숨기고 JS로 넘기는 덱                 | 확인            | 확인           | 확인        | 원본 스크립트는 저장본에 유지, 미리보기에서는 미실행. 캔버스 차트는 빈 칸 |
| reveal.js 구조                              | 확인            | 확인           | 확인        | reveal.js 라이브러리 자체를 쓰는 실제 파일은 미확인                       |
| EUC-KR, CRLF, 대문자 태그, 따옴표 없는 속성 | 확인            | 확인           | 확인        | 저장 시 UTF-8로 변환                                                      |
| 스크립트가 내용을 전부 만드는 파일          | 감지하고 안내   | 불가           | -           | 렌더링된 HTML을 저장해 열어야 함                                          |
| 일반 웹 페이지                              | 임의 분할 안 함 | 한 장으로 편집 | 확인        | CSS 선택자로 직접 구분 가능                                               |
| Tailwind CDN 등 스크립트 기반 CSS           | -               | 미확인         | -           | 스타일이 빠져 보일 것으로 예상                                            |

## 출력 앱

| 대상                               | 상태                                                                 |
| ---------------------------------- | -------------------------------------------------------------------- |
| PowerPoint 16 (Windows)            | 확인: 파일 열기, 객체, 좌표, 노트, 렌더링                            |
| Keynote, Google Slides             | **확인하지 않음**                                                    |
| LibreOffice                        | CI 변환 스모크 테스트 통과(호환성 증명 아님). 렌더링은 확인하지 않음 |
| `file://`로 연 HTML, 네트워크 차단 | 확인: Chrome, Edge                                                   |
| 인쇄                               | 페이지 수와 비율 확인. 사람이 인쇄 창을 조작한 시험은 없음           |

## 언어

메뉴는 한국어와 영어를 지원합니다. 스캔 결과, 가져오기 경고, 속성 패널은 현재 한국어입니다.

## 키보드 단축키

| 키                    | 동작                                                       |
| --------------------- | ---------------------------------------------------------- |
| Ctrl+S / Ctrl+Shift+S | 저장 / 다른 이름으로 저장                                  |
| Ctrl+Z / Ctrl+Y       | 실행 취소 / 다시 실행                                      |
| Ctrl+C, X, V          | 복사, 잘라내기, 붙여넣기                                   |
| Ctrl+D                | 복제 (편집기에 포커스가 있을 때 브라우저 책갈피 대신 동작) |
| Ctrl+A                | 전체 선택                                                  |
| Ctrl+G / Ctrl+Shift+G | 그룹 / 그룹 해제                                           |
| 방향키, Shift+방향키  | 1 / 10 단위 이동                                           |
| Tab, Shift+Tab        | 요소 순서대로 선택                                         |
| Enter, 더블클릭       | 글자 편집                                                  |
| Delete                | 삭제                                                       |
| F5 / Shift+F5         | 처음부터 / 현재 슬라이드부터 발표                          |
| Shift+드래그          | 축 고정 이동, 비율 고정 해제                               |
| Ctrl+크기 조절        | 중심 기준                                                  |
| Alt+드래그            | 스냅 끄기                                                  |

레거시 모드: 더블클릭으로 글자 편집, Ctrl+Enter로 확정, Esc로 취소.

Windows Chrome/Edge에서 자동 테스트로 확인한 것은 저장, 실행 취소, 복제, 전체 선택, 이동, Tab 선택, 삭제 관련 경로입니다. 다른 OS의 단축키 충돌은 확인하지 않았습니다.
